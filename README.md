# BOMIS Purnia ICT Tracker

A professional, cloud-based Progressive Web App (PWA) designed to streamline information and communication technology (ICT) management at Birla Open Minds International School (BOMIS), Purnia.

## 🚀 Overview

The **ICT Tracker** is a specialized tool built to automate educational and administrative tasks within the school's ICT department. It allows for efficient tracking of student progress, management of lab rosters, and secure data backups, ensuring a seamless digital workflow for teachers and staff.

## ✨ Key Features

- **Student Progress Tracking:** Monitor and record the academic advancement of students across various grades (Grades 3–7).
- **Lab Roster Management:** Easily manage and view computer lab schedules and student seating arrangements.
- **PWA Functionality:** Fully installable on mobile devices and desktops, providing an app-like experience with offline capabilities.
- **Data Security:** Features a robust system for backing up student progress and ICT records.
- **Automated Workflows:** Replaces manual record-keeping with digital entry to save time and reduce errors.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **PWA Features:** Web App Manifest (`manifest.json`), Service Workers for offline support.
- **Deployment:** Optimized for quick access via mobile and web browsers.

## 📲 Installation

Since this is a Progressive Web App, you can install it directly from your browser:

1. Open the app link in Chrome or Edge.
2. Click the **"Install"** icon in the address bar or select **"Add to Home Screen"** from the browser menu.
3. Launch the **ICT Tracker** directly from your app drawer or desktop.

## 📂 Project Structure

- `index.html`: The core interface and logic for the tracker.
- `manifest.json`: Configuration for PWA installation and UI theme.
- `logo.png`: Official branding for the application.
- `README.md`: Project documentation.
